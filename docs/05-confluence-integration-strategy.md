# 📚 5. Stratégie d'Intégration Confluence x Jira (Knowledge Base)

## 🎯 Architecture de l'Espace Confluence `KOLLECTA Knowledge Base`

Afin d'assurer la centralisation de la documentation fonctionnelle et la traçabilité avec l'exécution technique sous Jira, l'espace Confluence **`KOLLECTA Knowledge Base`** a été configuré avec la structure suivante :

```text
KOLLECTA Knowledge Base (KB)
├── 🚀 Onboarding & Team Policies
├── 📄 Product Requirements Documents (PRD)
│   └── PRD - Module KYC & Verification d'Identite
├── 🛠️ Technical Architecture & API Spec
├── 🔄 Release Notes & Changelogs
└── 🚨 Incident Management & Post-Mortems
